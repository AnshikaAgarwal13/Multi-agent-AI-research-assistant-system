# Multi-Agent AI Research Assistant System

## Overview

A multi-agent AI research assistant system designed to automate research workflows using specialized AI agents for web search, content extraction, report generation, and intelligent response evaluation.

The system leverages agent orchestration pipelines and Generative AI workflows to enable contextual reasoning, automated research analysis, and collaborative multi-agent task execution.

## Features

* Multi-agent AI orchestration workflows
* Automated web research pipelines
* Intelligent content extraction workflows
* AI-generated structured research reports
* Automated response evaluation and review
* Context-aware conversational interactions
* Multi-step reasoning workflows
* Interactive Streamlit-based interface

## Tech Stack

* Python
* LangChain
* Streamlit
* Generative AI APIs
* Agentic AI workflows

## AI Capabilities

* Multi-agent orchestration systems
* Prompt-driven reasoning workflows
* AI-powered research automation
* Intelligent task delegation across agents
* Automated report generation pipelines
* AI-assisted response evaluation

## Architecture

The system uses a multi-agent pipeline architecture where specialized AI agents collaborate to automate research workflows.

### Workflow Pipeline

User Query
↓
Search Agent
↓
Reader Agent
↓
Writer Agent
↓
Critic Agent
↓
Final Research Output


## Core Functionalities

## Search Agent

Retrieves relevant information and sources from the web based on user queries.

## Reader Agent

Processes and extracts meaningful content from retrieved sources.

## Writer Agent

Generates structured and detailed research reports using extracted information.

## Critic Agent

Reviews and evaluates generated reports for quality, clarity, and completeness.



* agents.py → AI agent definitions
* pipeline.py → Agent orchestration workflows
* tools.py → Utility and helper tools
* app.py → Streamlit frontend interface
